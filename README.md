# Credit Card Fraud Detection

## Overview
This project is part of the CodSoft Machine Learning Internship.

The objective is to build a machine learning model capable of identifying fraudulent credit card transactions using historical transaction data.

---

## Dataset

- fraudTrain.csv
- fraudTest.csv

**Note:** Due to GitHub file size limitations, the dataset is not included in this repository.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Machine Learning Workflow

1. Load Dataset
2. Exploratory Data Analysis (EDA)
3. Data Preprocessing
4. Feature Engineering
5. Label Encoding
6. Train/Test Split
7. Random Forest Classifier
8. Model Evaluation
9. Fraud Prediction
